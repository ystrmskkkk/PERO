# PERO — классика как игра

**PERO** — веб-приложение, которое превращает чтение классики в прохождение игры. Книга разбита на акты и уровни, как курс в Duolingo: читаешь отрывок, отвечаешь на вопросы по тексту, проходишь мини-игры и собираешь карточки героев, предметов и мест.

**Демо:** [ystrmskkkk.github.io/PERO](https://ystrmskkkk.github.io/PERO/) — лучше всего открывать с телефона.

> Статус: рабочий прототип (версия кеша `v63`). Целиком пройти можно «Капитанскую дочку» А. С. Пушкина: 5 актов, 20 уровней и финал книги.

---

## Зачем это

Школьную классику часто читают «по краткому содержанию» или не дочитывают вовсе: текст длинный, язык устаревший, непонятно, ради чего стараться. PERO решает это игровыми приёмами:

- **Маленькие шаги.** Глава делится на уровни по несколько минут чтения.
- **Понятный язык эпохи.** Устаревшие слова подчёркнуты, нажатие открывает пояснение.
- **Проверка без скуки.** Вместо пересказа — короткие вопросы прямо по тексту и мини-игры в финале акта.
- **Видимый прогресс.** Карта путешествия дорисовывается по мере чтения, копятся опыт, серия дней и коллекция карточек.

Приложение рассчитано на читателей любого возраста: в каталоге есть фильтр по возрасту.

### Уровень

Каждый уровень проходит в три этапа: **Чтение → Задания → Награда**.

- **Чтение.** Отрывок главы с эпиграфом и иллюстрацией-гравюрой (часть иллюстраций анимирована). Приложение помнит, где ты остановился.
- **Словарь эпохи.** 26 пояснений к словам вроде «кибитка», «буран», «премьер-майор», «самозванец».
- **Вопросы по тексту.** 32 проверочных вопроса с пояснением и цитатой из повести.
- **Портрет по памяти.** Собери внешность героя по чертам (возраст, сложение, борода, глаза…), а потом сравни со своим вариантом с описанием из книги.

## Как это устроено

PERO написано без фреймворков и сборки: всё приложение — один файл `index.html` с HTML, CSS и JavaScript.

- **PWA.** `manifest.webmanifest` и `sw.js` позволяют поставить приложение на экран «Домой» и открывать его без интернета.
- **Офлайн-кеш.** Страница загружается из сети, если она есть (так быстро приходят обновления), иначе из кеша. Картинки и шрифты сначала берутся из кеша.
- **Прогресс** хранится в `localStorage` браузера под ключом `bq-proto`. Сервера и аккаунтов нет.
- **Графика:** иллюстрации в WebP (папка `a/`), портреты и иконки — SVG прямо в коде, мини-игры рисуются на `<canvas>`.
- **Звук** синтезируется через Web Audio API, без аудиофайлов.
- **Шрифты:** Old Standard TT и PT Serif из Google Fonts.

### Структура репозитория

| Файл | Зачем |
| --- | --- |
| `index.html` | Само приложение: разметка, стили, логика и тексты уровней |
| `manifest.webmanifest` | Название, цвета и иконки приложения |
| `sw.js` | Офлайн-кеш: список файлов и правила загрузки |
| `a/` | Иллюстрации и слои анимаций (WebP/PNG) |
| `apple-touch-icon.png`, `icon-*.png` | Иконки для экрана «Домой» |

## Запуск локально

Service worker работает только через `http://localhost` или HTTPS, поэтому открывать `index.html` двойным кликом не стоит. Нужен любой локальный сервер, например:

```bash
git clone https://github.com/ystrmskkkk/PERO.git
cd PERO
python3 -m http.server 8000
```

Затем открой в браузере `http://localhost:8000`.

## Публикация на GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажми **Save**.
3. Через 1–2 минуты появится ссылка вида `https://ЛОГИН.github.io/PERO/`.

Альтернатива — [Netlify Drop](https://app.netlify.com/drop): перетащить папку в окно браузера (нужен бесплатный аккаунт).

## Установка на iPhone

1. Открой ссылку **в Safari** (в других браузерах на iPhone нужного пункта может не быть).
2. Нажми **Поделиться** (квадрат со стрелкой вверх).
3. Выбери **На экран «Домой»** → **Добавить**.
4. Запускай с иконки: приложение откроется во весь экран, без адресной строки.

На Android в Chrome то же самое делается через меню **⋮ → Добавить на главный экран**.

## Обновление

- Изменил только `index.html` — просто загрузи его в репозиторий. Через минуту-две открой приложение с интернетом, и подтянется новая версия.
- Добавил или заменил картинки — также увеличь номер версии в `sw.js` (`const CACHE = 'pero-v63'` → `'pero-v64'`) и добавь новые файлы в список `ASSETS`. Иначе у тех, кто уже открывал приложение, останутся старые картинки.
- Если обновление не пришло, закрой приложение свайпом из переключателя и открой снова.

## Полезно знать

- Прогресс хранится на самом устройстве. Если удалить иконку с экрана «Домой» или очистить данные сайта, прогресс сотрётся.
- У каждого, кто откроет ссылку, свой прогресс, так что ссылку можно спокойно раздавать тестерам. Сбросить прогресс можно в профиле.
- Первый запуск нужен с интернетом: так загрузятся шрифты и всё сохранится для офлайна.
- Это прототип: фрагменты текста сокращены и набраны для демонстрации. Перед бетой их нужно сверить с изданием.
