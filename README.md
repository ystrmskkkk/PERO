# PERO — как поставить на iPhone

Это веб-приложение (PWA). После публикации его можно добавить на экран «Домой»:
оно откроется во весь экран, со своей иконкой и будет работать без интернета.

## Что в папке

| Файл | Зачем |
| --- | --- |
| `index.html` | Само приложение |
| `manifest.webmanifest` | Название, цвета и иконки приложения |
| `sw.js` | Офлайн-кеш: приложение открывается без интернета |
| `apple-touch-icon.png`, `icon-*.png` | Иконки для экрана «Домой» |

## 1. Опубликовать на GitHub Pages (бесплатно, ~5 минут)

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажми **New repository**. Название — например `pero`. Выбери **Public** (для приватного репозитория Pages платный) и нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** (или **Add file → Upload files**).
4. Перетащи **все файлы из этой папки** (сами файлы, а не папку целиком) и нажми **Commit changes**.
5. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажми **Save**.
6. Подожди 1–2 минуты и обнови страницу: вверху появится ссылка вида
   `https://ТВОЙ-ЛОГИН.github.io/pero/`

## 2. Добавить на iPhone

1. Открой эту ссылку **в Safari** (в других браузерах на iPhone пункта может не быть).
2. Нажми **Поделиться** (квадрат со стрелкой вверх).
3. Выбери **На экран «Домой»** → **Добавить**.
4. Запускай с иконки: приложение откроется без адресной строки, как обычное.

## Как обновлять

Загрузи новый `index.html` в репозиторий тем же способом (**Add file → Upload files**, файл заменится).
Через минуту-две открой приложение с интернетом — подтянется новая версия.
Если не подтянулась, закрой приложение свайпом из переключателя и открой снова.

## Полезно знать

- Прогресс (XP, карточки, пройденные уровни) хранится на самом телефоне. Если удалить иконку с экрана «Домой», прогресс сотрётся.
- У каждого, кто откроет ссылку, свой прогресс — можно раздавать ссылку тестерам.
- Первый запуск нужен с интернетом: так загрузятся шрифты и всё сохранится для офлайна.
- Альтернатива GitHub: [Netlify](https://app.netlify.com/drop) — перетащить папку в окно браузера (нужен бесплатный аккаунт).
- Это прототип: фрагменты текста сокращены и набраны для демонстрации, перед бетой их нужно сверить с изданием.
